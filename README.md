# ProperTabGroups for Visual Studio

## Overview

**ProperTabGroups** is a cutting-edge Visual Studio extension designed to transform the way developers manage and interact with their editor tabs through an advanced group filtering system. This extension enhances the native tab management capabilities of Visual Studio by allowing users to create dynamic, filter-based tab groups. Tabs are automatically organized into these groups based on user-defined criteria, streamlining the coding workspace for efficiency and personalization.

## Features

- **Dynamic Tab Filtering**: Configure filters for tabs based on file type, project, custom patterns, and more, automatically organizing tabs into corresponding groups.
- **Custom Filter Groups**: Create filter groups with custom names and criteria tailored to specific workflow needs.
- **Filter Criteria Customization**: Define the filter criteria for each group using parameters such as filename patterns, modification status, or custom tags.
- **Group Visibility Controls**: Toggle filter groups' visibility to manage workspace clutter and enhance focus.
- **Custom Group Icons and Color Coding**: Assign unique icons and colors to each group for easy identification.
- **Persistence and Portability**: Save filter configurations for easy setup on any Visual Studio environment.
- **Intuitive Management and Rearrangement**: Easily manage and rearrange tabs within groups through a user-friendly interface.

## Installation

1. Open Visual Studio.
2. Navigate to **Extensions > Manage Extensions**.
3. Search for **ProperTabGroups** in the Online marketplace.
4. Click **Download** and follow the installation prompts.
5. Restart Visual Studio to activate the extension.

## Usage

- **Creating/Customizing Filter Groups**: Through the ProperTabGroups menu, create a new filter group, defining its criteria, and assigning a custom name, color, and icon.
- **Adjusting Filter Criteria**: At any time, modify the criteria of any filter group to better suit your organization needs.
- **Hiding/Showing Filter Groups**: Manage the display of different groups with visibility controls to keep your workspace focused.
- **Rearranging Tabs**: Manually rearrange tabs within their groups, despite automatic organization based on filters.
- **Persistence Across Sessions**: Your configurations and arrangements are saved, letting you seamlessly continue your work.
